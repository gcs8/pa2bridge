# PA2Bridge

A Home Assistant App for bounded, verified dbx DriveRack PA2 preset recall, output mute control, and read-only telemetry.

PA2Bridge discovers the PA2 MAC from the local neighbour table or Home Assistant network-integration data and uses it as a stable MQTT identity across IP changes. An App option provides a manual override.

See [DOCS.md](DOCS.md) for installation and safety requirements.
